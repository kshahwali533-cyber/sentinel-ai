Researcher Preview — controlled evaluation

This beta workspace records findings, evidence, remediation notes, and status for websites verified in your account. It is not a public bug-bounty program and does not itself grant permission to test any target.

Safety boundary: Do not test third-party systems or production assets unless the asset owner has given you explicit written authorization covering the exact host, paths, methods, dates, and exclusions. This Preview does not issue active-testing authorization or run exploit traffic.

Before an external assessment

  • Obtain a signed scope and a named point of contact from the asset owner.
  • Use a dedicated test account and non-production test data supplied for the assessment.
  • Keep testing non-destructive; no denial-of-service, credential theft, social engineering, persistence, destructive writes, or data exfiltration.
  • Stop immediately if real user data, secrets, or an out-of-scope system is encountered.
  • Submit findings privately with timestamps, reproducible steps, redacted evidence, impact, and remediation.

Current beta limitation: research cases, independent approval records, and an active bug-bounty submission/triage portal are not yet enabled. Findings entered below are private account records, not a formal vulnerability disclosure submission.
